## Publish the site
1. Put `index.html`, `style.css`, `script.js` and this `README.md` in the root of the `supunkarunarathna` repository.
2. Go to **Settings, then Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
3. The site goes live within a minute or two at the URL above.
4. Replace the writeup links in the Technical writeups section of `index.html` with your real writeup paths.

To add a writeup, copy one `<a class="row">` block in the `#writeups` section and change the title, summary and link.
