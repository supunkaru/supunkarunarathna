About

Cyber Security Analyst with over six years in telecommunications network and security engineering, including 3+ years of hands-on security operations. I analyse security events, investigate incidents, improve detection capability and support proactive cyber defence across complex enterprise environments.

My work covers security monitoring, incident response, SIEM, threat detection, vulnerability management and security investigations in enterprise and telecom settings. I analyse alerts, investigate suspicious activity, perform log and event analysis, and support response and remediation. My background in network security is backed by working knowledge of MITRE ATT&CK, phishing, malware analysis, ISO 27001 and NIST CSF.

I am passionate about Threat Hunting, Detection Engineering, DFIR, Cloud Security and Microsoft Security technologies, and I document the practical labs I build on industry platforms.
